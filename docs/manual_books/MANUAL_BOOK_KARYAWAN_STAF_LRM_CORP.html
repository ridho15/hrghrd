MODUL 01 Login & Pengikatan Smartphone Resmi (Device Binding)
Web Portal & Mobile App
Status Device Terikat
Beranda Akun Karyawan
Cara Aktivasi Akun Pertama Kali:
  1. Buka aplikasi HR Group HRD Mobile di smartphone pribadi Anda.
  2. Masukkan alamat email kantor Anda (misal: karyawan@example.test) dan kata sandi default.
  3. Klik tombol Masuk ke Akun.
  4. Sistem secara otomatis mengikat smartphone Anda ke akun Anda (Device Hash Binding).
Aturan 1 HP = 1 Akun: Anda dilarang login di smartphone rekan kerja. Jika Anda berganti HP baru, lapor ke HR Admin untuk reset binding gawai.

MODUL 03 Prosedur Absen Masuk (Check-In) & Pulang (Check-Out)
Tab Presensi Aplikasi Mobile
1. Indikator GPS Hijau
2. Shift Kerja Hari Ini
Langkah Melakukan Check-In:
  1. Nyalakan Lokasi/GPS pada smartphone Anda sebelum masuk kantor.
  2. Buka aplikasi mobile → Masuk ke tab Presensi.
  3. Pastikan teks berbunyi hijau: "Lokasi Valid (Di Dalam Radius Cabang)".
  4. Arahkan kamera smartphone ke monitor display kantor yang menampilkan QR Code Dinamis.
  5. Scan akan berhasil dalam 1 detik dan memunculkan pop-up hijau Check-In Berhasil.
Langkah Melakukan Check-Out (Pulang):
  1. Setelah jam kerja shift selesai, buka kembali tab Presensi.
  2. Scan kembali QR Code pada monitor kantor untuk konfirmasi Check-Out.
Toleransi Terlambat: Maksimal toleransi keterlambatan adalah 15 menit. Lewat dari 15 menit akan dikenakan potongan keterlambatan pada slip gaji.
MODUL 04 Cara Lapor Kendala Presensi (Attendance Exception)
Tab Presensi → Lapor Kendala
Kapan Menggunakan Fitur Ini?

Gunakan tombol ini jika smartphone Anda mengalami kendala GPS di basement/gedung, kamera rusak, atau monitor QR kantor mati lampu.

Cara Mengirimkan Laporan:
  1. Di tab Presensi, klik tombol Lapor Kendala Presensi.
  2. Pilih tipe kendala (GPS Lemah / Layar Display Mati / Kamera Error).
  3. Isi Jam Kedatangan Sebenarnya saat Anda tiba di kantor secara jujur.
  4. Tuliskan catatan singkat kronologi kendala → Klik Kirim Laporan.
  5. Manager Cabang Anda akan memeriksa dan menyetujui jam kedatangan Anda.
Tips: Segera laporkan kendala di pagi hari agar Manager dapat menyetujuinya sebelum jam kerja berakhir.
MODUL 05 Memeriksa Jadwal Shift Kerja Pribadi
http://127.0.0.1:8003/shifts
Cara Cek Jadwal:
  1. Buka tab Jadwal di aplikasi mobile atau menu Shift di portal web.
  2. Lihat daftar tanggal kerja, jam masuk, jam pulang, dan lokasi cabang tugas Anda.
  3. Pastikan status shift bertuliskan Approved.
MODUL 06 Pengajuan Cuti Tahunan & Izin Sakit (Upload Surat)
http://127.0.0.1:8003/leave/create
Langkah Mengajukan Izin / Cuti:
  1. Buka menu Cuti / Izin → Klik + Ajukan Cuti.
  2. Pilih tipe: Cuti Tahunan atau Izin Sakit.
  3. Pilih tanggal mulai dan tanggal selesai izin.
  4. Tuliskan alasan izin pada kolom keterangan.
  5. Wajib untuk Izin Sakit: Unggah foto Surat Keterangan Dokter klinik/RS resmi.
  6. Klik tombol Kirim Permohonan. Pantau status approval di menu riwayat cuti.

MODUL 08 Mengubah Kata Sandi & Menjaga Keamanan Akun
Menu Profil → Ubah Kata Sandi
Cara Ubah Password:
  1. Buka tab Profil di aplikasi mobile atau klik nama Anda di web portal pojok kanan atas.
  2. Klik opsi Ubah Kata Sandi.
  3. Masukkan password lama Anda, lalu masukkan password baru (minimal 8 karakter kombinasi huruf & angka).
  4. Klik tombol Simpan Perubahan.
Keamanan: Jangan pernah membagikan password atau meminjamkan smartphone terdaftar kepada siapa pun.
