MODUL 01 Login & Pengikatan Smartphone Resmi (Device Binding)
Mobile App & Web Portal
Status Device Terikat
Beranda Akun Karyawan
Cara Aktivasi Akun Pertama Kali:
  1. Buka aplikasi HR Group HRD Mobile pada smartphone pribadi Anda (atau buka web portal pada peramban).
  2. Ketikkan Username atau Email resmi Anda yang telah didaftarkan oleh HRD.
  3. Masukkan kata sandi awal Anda (default: 12345678 jika baru direset oleh HRD).
  4. Klik tombol Masuk ke Akun.
  5. Pada saat login pertama kali, sistem secara otomatis mengikat smartphone Anda ke akun Anda (Device Hash Binding).
Kebijakan 1 HP = 1 Akun: Anda dilarang login di smartphone rekan kerja. Jika Anda berganti HP baru, segera laporkan ke Super Admin / HRD untuk melakukan Reset Kunci HP.

MODUL 03 Prosedur Absen Masuk (Check-In) & Pulang (Check-Out)
Tab Presensi Aplikasi Mobile
1. Indikator GPS Hijau
2. Shift Kerja Hari Ini
Langkah Melakukan Check-In Masuk:
  1. Nyalakan Lokasi / GPS pada smartphone Anda sebelum memasuki area kantor cabang.
  2. Buka aplikasi mobile → Masuk ke tab Presensi.
  3. Pastikan indikator lokasi berbunyi hijau: "Lokasi Valid (Di Dalam Radius Cabang)".
  4. Arahkan kamera smartphone Anda ke layar monitor display kantor yang menampilkan QR Code Dinamis.
  5. Pindai QR Code hingga muncul notifikasi hijau Check-In Berhasil.
Langkah Melakukan Check-Out Pulang:
  1. Setelah jam kerja shift selesai, buka kembali tab Presensi.
  2. Arahkan kamera ke QR Code monitor kantor untuk melakukan konfirmasi Check-Out.
Toleransi Keterlambatan: Batas maksimal toleransi keterlambatan adalah 15 menit. Keterlambatan melebihi 15 menit otomatis tercatat dan dikenakan pemotongan pada slip gaji bulanan.
MODUL 04 Cara Lapor Kendala Presensi (Attendance Exception)
Tab Presensi → Lapor Kendala
Kapan Fitur Ini Digunakan?

Gunakan formulir ini jika Anda sudah berada di lokasi kerja namun smartphone mengalami kendala GPS di basement gedung, kamera ponsel error, atau monitor display QR kantor mati lampu.

Cara Mengirimkan Laporan:
  1. Pada tab Presensi, klik tombol Lapor Kendala Presensi.
  2. Pilih tipe kendala (GPS Lemah / Layar Display Mati / Kamera Error).
  3. Isi Jam Kedatangan Sebenarnya saat Anda tiba di kantor secara jujur.
  4. Tuliskan uraian singkat kendala pada kolom catatan → Klik Kirim Laporan.
  5. Manager Cabang akan memverifikasi dan menyetujui klaim jam kedatangan Anda.
Tips: Segera laporkan kendala di awal jam kerja agar Manager Cabang dapat segera melakukan verifikasi sebelum shift berakhir.
MODUL 05 Memeriksa Jadwal Shift Kerja Pribadi
Rute: /shifts
Cara Cek Jadwal Tugas:
  1. Buka tab Jadwal di aplikasi mobile atau menu Shift di portal web.
  2. Periksa tanggal kerja, jam mulai, jam selesai, dan cabang penugasan Anda.
  3. Pastikan status jadwal telah bertuliskan Approved.
MODUL 06 Pengajuan Cuti Tahunan & Izin Sakit (Upload Surat Dokter)
Rute: /leave
Langkah Pengajuan Izin / Cuti:
  1. Buka menu Cuti / Izin → Klik tombol + Ajukan Cuti.
  2. Pilih kategori: Cuti Tahunan atau Izin Sakit.
  3. Pilih tanggal mulai dan tanggal selesai izin.
  4. Tuliskan alasan permohonan secara jelas.
  5. Wajib untuk Izin Sakit: Unggah foto Surat Keterangan Dokter dari klinik/rumah sakit resmi.
  6. Klik tombol Kirim Permohonan dan pantau status persetujuan pada riwayat cuti.

MODUL 08 Mengubah Kata Sandi & Menjaga Keamanan Akun
Menu Profil → Ubah Kata Sandi
Langkah Mengubah Kata Sandi Mandiri:
  1. Buka tab Profil di aplikasi mobile atau klik nama Anda di web portal pojok kanan atas.
  2. Klik tombol Ubah Kata Sandi.
  3. Ketikkan kata sandi lama Anda (atau kata sandi default 12345678 jika baru direset).
  4. Masukkan kata sandi baru (minimal 8 karakter kombinasi huruf & angka) dan konfirmasi ulang.
  5. Klik tombol Simpan Perubahan.
Privasi Akun: Jangan pernah membagikan kata sandi Anda atau meminjamkan smartphone terdaftar kepada siapa pun. Seluruh transaksi presensi tercatat otomatis dalam audit log.
